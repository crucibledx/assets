# Assets — Agent Context

> Centralized visual assets for all Crucible products. Single source of truth — edit here, reference everywhere.

## Identity

- **Repo:** `crucibledx/assets`
- **Version:** simple incrementing tags (`v1`, ...), no semver

## What It Does

Stores all diagrams, terminal recordings, logos, and visual assets for every Crucible product. Other repos reference assets via raw GitHub URLs.

## Structure

```
<category>/
  <asset-type>/
    source-file.drawio          ← editable source
    source-file.tape            ← editable source (VHS terminal recording)
    fixtures/                   ← test data (for demos)
    light/
      output-file.svg           ← light-theme output (PRIMARY)
    dark/
      output-file.svg           ← dark-theme output (SVG diagrams: GENERATED from light; demo GIFs: rendered from .tape)
```

### Categories

| Category | Description |
|----------|-------------|
| `forge/` | Forge CLI assets |
| `platform/` | AI resource lifecycle platform (skills, specimens) |
| `ember/` | Ember — AI observability |
| `crucible/` | Crucible-wide assets (ecosystem, product phases) |
| `branding/` | Logos, wordmarks, icons, color references |

### Asset Types

| Type | Sources | Outputs |
|------|---------|---------|
| `diagrams/` | `.drawio` | `.svg`, `.png` |
| `demos/` | `.tape` | `.gif` |

## Key Rules

- **Light is primary for SVG diagrams** — always export/edit the light theme; dark SVGs are GENERATED by
  `generate-dark-svgs.sh`, which injects `filter: invert(1) hue-rotate(180deg)` into each SVG
- **Demo GIFs are not generated from light** — `generate-demos.sh` renders each theme from the `.tape` source
  (`--dark` / `--light`, both by default)
- **Never export dark from draw.io** — it looks ugly
- **Always optimize SVGs** after exporting (SVGO, typically 5-10x size reduction)
- **Git LFS** tracks heavy binaries via `.gitattributes` (`.gif`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.mp4`); SVGs stay in normal git
- `test/` exists but is currently empty

## Scripts

```bash
scripts/generate-demos.sh [--dark|--light] [--mp4|--gif] [--changed] [category]   # tapes → GIFs/MP4
scripts/export-diagrams.sh [--format svg|png] [--scale N] [--changed] [category]  # drawio → SVG/PNG
scripts/generate-dark-svgs.sh [category|file]                                      # light SVGs → dark variants
scripts/optimize-svgs.sh [--dry-run] [--changed] [category]                        # SVGO optimization
```

All scripts accept a category (or path) filter. `--changed` is supported by generate-demos, export-diagrams, and
optimize-svgs, not by generate-dark-svgs.

## Referencing from Other Repos

```markdown
![diagram](https://github.com/crucibledx/assets/raw/main/platform/diagrams/light/flow.svg)
```

For dark/light switching:
```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://github.com/crucibledx/assets/raw/main/.../dark/file.svg">
  <img alt="..." src="https://github.com/crucibledx/assets/raw/main/.../light/file.svg">
</picture>
```

For immutable references, use tags: `.../raw/v1/...`

## Prerequisites

- draw.io desktop — diagram exports
- VHS (`brew install charmbracelet/tap/vhs`) — demo GIF generation
- SVGO (`bunx svgo`) — SVG optimization
- Git LFS (`brew install git-lfs`) — large file storage
